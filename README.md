# Out of Our Hands

A design theory instrument for ARCH 602. If the designer writes the rules, who authors the form?

A signature starts a flock. Three studies give cohesion, separation, or alignment more influence. The Experiment brings those forms together. The designer sets the conditions. The form is what the rules do with a mark nobody specified in advance.

The shared page is [https://toriefindlay.github.io/ARCH-602---DESIGN-THEORY-/](https://toriefindlay.github.io/ARCH-602---DESIGN-THEORY-/).

## Run

Open `index.html` in a browser. No install, account, or build step. Instrument Sans loads from Google Fonts when the page is online. The simulation, images, and STL export run in the browser.

Sign in The Gesture, then choose Run the rules. Pause, Restart, and Fit view sit with the studies. Another beginning keeps the signature and changes only the start. The same signature, the same rules, and the same beginning return the same object.

## What a signature changes

Agents are placed along the stroke. Turns in the signature become nodes, and the modifiers act there. Each study uses the same signature and gives one behaviour the lead.

- **Cohesion** gathers agents around the turns.
- **Separation** opens space around the turns, and keeps agents and tubes out of a zone at each node.
- **Alignment** draws coordinated streams between the turns.

In The Experiment, the three forms sit in one view. The sliders change the size of each form. Symmetry mirrors that view only and leaves the studies alone.

## Modifiers and colour

Choose up to one modifier from each category. The choice applies to every study.

- **Texture:** Reflection, Stripes
- **Volume:** Bubbles, Porosity
- **Motion:** Reaction, Murmuration

Each category has its own strength. Colour is a tint shared by every study. Tone changes lightness and saturation. Original returns the form to chalk.

## Print

Download STL saves the current experiment: the visible form, the three sizes, the modifiers, and symmetry when it is on. Backgrounds, lights, guides, and the interface are left out. Print size is the longest side, in millimetres, and starts at 100. The file is `out-of-our-hands.stl`.

The tubes are open at their ends, and the form is many separate pieces. The note under the button reports that. The export does not cap or join them.

## What the model assumes

One hundred and seventy agents follow cohesion, separation, and alignment, after Craig Reynolds. The page names the other sources. Porosity, bubbles, and reaction are simplifications of Philip Ball, not a model of bone, foam, or chemistry. This is a design experiment. It is not a structural or material simulation.
